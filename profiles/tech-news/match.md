# Technology news profile

Use this profile for timely applied-AI engineering developments that change a near-term product or delivery decision: evaluation, agents, RAG, tool use, MCP, context, reliability, safety, data, cost, latency, permissions, and substantive open-source releases with a runnable use case.

Typical items include substantial releases, research breakthroughs, security incidents, industry announcements, technical analyses tied to a recent event, and community discussions that add practical insight.

Prefer official technical reports, release notes, reproducible examples, implementation evidence, and postmortems. Raw papers, model architecture, training, chips, and inference internals belong here only when they affect an applied product choice soon. Do not use this profile for general consumer launches, finance-first coverage, routine updates, leaderboards without a decision, or promotion without implementation evidence.
